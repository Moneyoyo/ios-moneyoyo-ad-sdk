# Moneyoyo Ad SDK iOS

This repository contains releases for Moneyoyo Ad SDK for iOS.

See the [Releases](https://github.com/Moneyoyo/ios-moneyoyo-ad-sdk/releases) page for `MoneyoyoAdSDK.xcframework.zip`.

Installation using [Swift Package Manager](https://www.swift.org/documentation/package-manager/) is also supported.

## Requirements

- Xcode 16+
- iOS 15+

### Supported Ad Formats

| Format | Description                     |
|--------|---------------------------------|
| Banner | 320x50, 320x100, 300x250 (MREC) |
